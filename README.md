Ce dépôt est un environnement personnel de tests pour expérimenter et valider différentes configurations et pratiques de développement.
Il est **strictement** personnel et ne doit être utilisé que pour des tests.

## Objectif

Ce dépôt sert à :
- Tester les workflows GitHub Actions
- Valider les templates d'issues
- Expérimenter avec les conventions de commits
- Mettre en place des bonnes pratiques de développement

⚠️ **Note importante** : Ce dépôt est destiné uniquement aux tests et à l'apprentissage. Il ne contient pas de code de production.
